CORS -Cross ORIGIN Resource Sharing.
Browsers follow a rule called Same-Origin Policy.If browser front end runs on port 3000 but server is running on 5000.If browser 
try to access the port 5000 it gives cors error.Why because browser follow same origin policy.If server included the app.cors() that server tells to the browser we can allow this to access localhost:5000 to fetch the data.


const mysql = require('mysql2');

const connection = mysql.createConnection({
  host:"localhost",
  user:"root",
  password:"",
  database:"testdb"
});

this created only one connectioon per request.Other request need to wait to this request get finish.
User 1 request → uses connection
User 2 request → must wait
User 3 request → must wait

A pool creates multiple reusable connections.
const pool = mysql.createPool({
  connectionLimit:10
});
User 1 → connection 1
User 2 → connection 2
User 3 → connection 3
User 4 → connection 4 All request run in parallel.

Without pool:
API request
single DB connection
requests wait in queue

With pool:

API request
connection pool (10 connections)
Multiple queries run simultaneously.If 11 request comes means it wait in queue untill others get finish.
It does not gets failed it will wait.

Callback style:
db.query(sql,(err,result)=>{
   if(err){
      //console.log(err);
   }
});
Promise style:
try{
   const [rows] = await db.query(sql);
}catch(err){
   //console.log(err);
}
